# TentNets — Minecraft 1.21.1

Мод добавляет две натяжные сети, размещаемые между опорными точками:

- **Антидроновая сеть** (`tentnets:anti_drone_net`) — перехватывает сущности-снаряды по правилам и тегам мода.
- **Маскировочная сеть** (`tentnets:mask_net`) — камуфляжное полотно; скрывает ник игрока, находящегося под полотном (клиентская отрисовка).

## Поддерживаемые загрузчики

В репозитории находятся два самостоятельных проекта. Их JAR-файлы не взаимозаменяемы.

| Папка | Minecraft | Загрузчик | Выходной JAR |
|---|---|---|---|
| `tentnets-forge/` | 1.21.1 | Forge 52.x | `build/libs/tentnets-1.0.0.jar` |
| `tentnets-neoforge/` | 1.21.1 | NeoForge 21.1.x | `build/libs/tentnets-1.0.0.jar` |

Требуется **Java 21** и Gradle 8.8 или новее. Версии зависимостей заданы в `gradle.properties` каждого проекта.

## Сборка локально

Откройте терминал в нужной папке и выполните:

```bash
# Forge
cd tentnets-forge
gradle build

# NeoForge
cd ../tentnets-neoforge
gradle build
```

Готовый JAR появится в `build/libs/` соответствующего проекта. Для сервера установите именно тот JAR, который соответствует загрузчику сервера. Игрокам также понадобится соответствующая версия мода на клиенте.

## GitHub Actions

Workflow `.github/workflows/build.yml` собирает оба варианта при push и pull request и публикует JAR как отдельные build artifacts. Откройте вкладку **Actions**, выберите последний успешный запуск и скачайте артефакт `tentnets-forge-1.21.1` или `tentnets-neoforge-1.21.1`.

## Размещение сети

| Действие | Результат |
|---|---|
| ПКМ по блоку | Добавить опорную точку (до 8) |
| Shift + ПКМ | Натянуть сеть между точками (минимум 3) |
| ПКМ в воздух | Отменить последнюю точку |
| Shift + ПКМ в воздух, когда точек нет | Снять сеть, на которую смотришь (предмет возвращается) |

Точки подсвечиваются частицами, контур будущей сети — линиями. Максимальное расстояние от первой точки — 48 блоков.

## Настройка типов сущностей

Правила антидроновой сети задаются в `data/tentnets/tags/entity_type/`:

- `passthrough.json` — пропускает сущность;
- `explode.json` — вызывает взрыв без разрушения блоков;
- `catch.json` — ловит сущность.

Дополнительные моды можно поддержать, добавив ID их сущностей в соответствующий тег.

## Важное замечание о проверке

Исходники Forge взяты из предыдущего проекта. NeoForge-папка содержит отдельный порт под API NeoForge. В текущей среде не удалось выполнить Gradle-сборку (нет установленного Gradle и загрузка Gradle distribution недоступна), поэтому JAR здесь не объявляются проверенными. GitHub Actions автоматически попробует собрать оба проекта после загрузки репозитория; если компилятор обнаружит несовместимость API, лог сборки покажет точное место.
